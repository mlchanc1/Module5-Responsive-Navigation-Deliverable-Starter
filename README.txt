Site Description:
Explore Springfield is a three-page visitor information site designed to help users plan a visit to Springfield. The primary navigation provides access to Home, Visit, Things to Do, Food & Drink, Events, and Get support.

Responsive Navigation:
The site uses a narrow-first responsive navigation. At smaller widths, a Menu button controls the navigation. At wider widths, the navigation links are displayed horizontally. The current page is identified visually and with aria-current="page".

Accessibility and Interaction:
The navigation supports keyboard and pointer interaction. A skip link allows keyboard users to move directly to the main content. The Menu button can be activated with native button controls, and Escape closes an open menu and returns focus to the Menu button.

Testing Notes:
I tested the navigation using keyboard navigation, pointer interaction, a 320 CSS-pixel viewport, the breakpoint region, 200% zoom, JavaScript unavailable, and CSS unavailable. I also completed a peer navigation task test. The responsive navigation remained usable during the required tests.
